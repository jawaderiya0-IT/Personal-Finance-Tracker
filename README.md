# Personal Finance Tracker
## Description
Personal Finance Tracker is a simple Python console application that helps users manage their daily income and expenses. it allows users to add income, add expenses, check the current balance, view transaction history, and see a summary of all financial activities.
## Features
- Add Income
- Add Expense
- View Current Balance
- View Transaction History
- View Financial Summary
- Simple Menu Driven Program
- Easy to Use
## Technologies Used
- Python 3
## Sample Menu
1.Add Income
2.Add Expense
3.View Balance
4.View History
5.Summary
6.Exit
